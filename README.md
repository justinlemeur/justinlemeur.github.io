# Justin LE MEUR — Portfolio V3
Direction artistique minimaliste noir & or, sans images.
Téléversez le contenu de ce dossier à la racine du dépôt GitHub Pages `justinlemeur.github.io`.
Ajoutez `two-sides.mp3` et `arise.mp3` dans `music/` pour activer les lecteurs audio.
Modifiez `js/tracks.js` pour ajouter ou modifier les morceaux.


IMPORTANT — version autonome côté design : le CSS est également intégré dans chaque page HTML. Le dossier css/style.css reste fourni comme copie de référence.

Pour publier : téléversez le CONTENU du ZIP à la racine du dépôt GitHub (pas le dossier parent), puis validez le commit. Vérifiez que index.html est directement à la racine.
